The tablet in your drawer still works

Its screen is fine. Its battery is fine. What died was software support — and then every whiteboard tool decided it needed a GPU.

◱

No canvas, no WebGL

Notes are plain HTML elements. Miro, Excalidraw and tldraw all render to a GPU canvas, which is precisely what a 2012 tablet cannot do.

◷

No WebSocket

Sync is ordinary HTTP polling. It survives flaky wifi, sleeping tablets and captive portals far better than a socket, and it works in browsers older than WebSocket itself.

◼

Built for e-paper

An e-ink mode for Boox, Kindle and reMarkable: colour becomes border texture, animation disappears, and polling slows so the panel stops refreshing under you.

▤

A mode with no JavaScript at all

For hardware older than the idea of a web app, the whole wall renders server-side as plain HTML with a form. It is not pretty. It works.

Start from a layout

A template just seeds the wall with notes. Nothing locks afterwards, so a kanban board can quietly become something else when the work changes shape.

Where it runs

Honest limits, including the one we cannot engineer around.

DeviceAtticMiroExcalidraw
Current laptop or phoneYesYesYes
iPad 2 / 3 (iOS 9)YesNoNo
Android 5–7 tabletYesNoNo
E-ink reader (Boox, Kindle)YesNoNo
Pre-2008 machine, over your LANBasic modeNoNo
Pre-2008 machine, over the internetNo — see belowNoNo

That last row is not a missing feature. A pre-2008 device cannot negotiate modern TLS and has no current certificate authorities in its trust store, so it can never reach an HTTPS site. On your own network, over plain HTTP, it works fine. We would rather say so than let you find out.

Run it yourself

Self-hosting is the product today, it is free, and it stays free. A hosted option will come later for people who do not want to run a machine — hosting is what actually costs money, so hosting is what will cost money.
